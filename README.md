# Coimbatore Hostel Checklist — PWA

## Files
- `Coimbatore_Hostel_Packing_Checklist.html` — the app
- `manifest.webmanifest` — install/home-screen metadata
- `sw.js` — offline caching
- `icons/icon.svg` — app icon

## Install on Android
1. Upload all files/folders to a static HTTPS host (for example GitHub Pages).
2. Open the HTML page in Chrome.
3. Tap **⋮ → Add to Home screen** (or **Install app**, if shown).
4. Launch it from the home screen.

The checklist remembers checked items on the same device/browser using local storage and includes a reset button.
